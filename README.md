# Two-Dice Sum Probability Distribution Viz
Live histogram showing actual two-dice roll results converging toward theoretical probability distribution.
## Features
- Auto-roll at configurable speed (1–100 rolls/sec) or single manual roll
- Histogram bars for each sum from 2 to 12
- Theoretical probability overlaid as white tick lines on each bar
- Bars colored green (within tolerance) or orange (off from expected)
- Stats: total rolls, most frequent sum, current streak of same sum
- Reset button and 10,000 roll cap
## Tech
Static SPA · Tailwind CDN · Canvas/localStorage
